# Ficha de componente: Swipe Actions (`AqSwipeActions`)

- **Nombre:** Swipe Actions / Deslizamiento en fila (`AqSwipeActions`)
- **Nivel de origen:** `native-pattern` (Nivel 3) estilizado al 100 % con tokens Polaris
- **Anatomía:** Contenedor de fila que envuelve el contenido principal del ítem de lista. Al deslizar horizontalmente hacia la izquierda o derecha con gesto táctil continuo, revela una o más acciones de fondo (ejemplo: acción destructiva de eliminar o acción secundaria de archivar/destacar), con icono y etiqueta visual. Admite umbral de activación (threshold) para ejecutar la acción al soltar tras sobrepasar el límite, o botones táctiles revelados.
- **Variantes y tamaños:**
  - Deslizamiento hacia la izquierda: Acción destructiva (`DangerAction`) o acción secundaria (`SecondaryAction`).
  - Deslizamiento hacia la derecha: Acción de marcado o favoritos.
  - Altura adaptable a la fila que envuelve (mínimo interactivo 48 dp).
- **Estados:**
  - `Idle` / Cerrado: Contenido visible sin desplazamiento.
  - `Dragging`: Desplazamiento progresivo siguiendo el dedo del usuario.
  - `Revealed`: Acciones descubiertas listas para ser pulsadas.
  - `Dismissed`: Fila colapsando tras completar la acción (si es de descarte).
- **Tokens Polaris:**
  - Fondo acción destructiva: `AqColor.BgFillDanger` (`#D72C0D`).
  - Texto e icono acción destructiva: `AqColor.TextInverse` (`#FFFFFF`).
  - Fondo acción secundaria: `AqColor.BgSurfaceSecondary` (`#F7F7F7` / `#303030`).
  - Texto e icono secundario: `AqColor.Text`.
  - Animación de rebote y retorno: `AqMotion.DurationBase` (200 ms), `AqMotion.EasingBase`.
- **Accesibilidad:**
  - Muy importante: El gesto de deslizamiento no es accesible por sí solo para usuarios de TalkBack o lectores de pantalla. Por lo tanto, `AqSwipeActions` expone automáticamente las acciones mediante `Modifier.semantics { customActions = listOf(...) }`, permitiendo que el lector de pantalla anuncie y ejecute las acciones sin requerir el gesto físico.
  - Tamaño de botón de acción revelada: mínimo 48 dp de ancho y alto interactivo.
- **Comportamiento Claro / Oscuro:** Los fondos de acción conservan el contraste reglamentario WCAG AA en ambos modos.
- **Notas de adaptación:** Ni Polaris ni Moon Design definen un componente de swipe actions táctil. Se toma la convención nativa de Android (`SwipeToDismissBox`) e iOS y se reemplazan el 100 % de los valores visuales por tokens Polaris.
- **Pantallas consumidoras:**
  - `DestinationsScreen` (S01): filas de destino con acciones "Marcar favorito / Quitar favorito" y "Eliminar" (este último abre el diálogo de confirmación vigente).
  - `OperationListScreen` (S07-list): filas de operación con acciones "Editar" y "Eliminar" (este último abre el diálogo de confirmación vigente).
