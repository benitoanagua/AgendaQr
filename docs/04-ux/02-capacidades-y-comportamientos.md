# UX — Capacidades y comportamientos confirmados

## Capacidades

La experiencia permite:

- visualizar destinos;
- buscar;
- organizar mediante categorías;
- organizar mediante favoritos;
- consultar recientes;
- crear/importar;
- editar;
- reemplazar QR;
- eliminar;
- mostrar QR a pantalla completa;
- compartir QR.

## Comportamientos confirmados

- La recuperación de QR es central.
- El destino se distingue mediante metadatos, no solamente mediante la imagen.
- La visualización principal puede realizarse sin conexión.
- El QR puede compartirse mediante las capacidades del sistema.

## No definido

No se fija un diseño visual concreto ni una arquitectura de navegación.

Tampoco se inventan:

- animaciones;
- textos de interfaz;
- mensajes de error;
- validaciones adicionales.
