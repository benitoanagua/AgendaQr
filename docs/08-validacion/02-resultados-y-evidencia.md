# Validación — Resultados consolidados

## Evidencias

1. La recuperación es el momento crítico que debe medirse.
2. `time_search_to_view` es una métrica útil para medir el tiempo desde la búsqueda hasta que el QR es visible.
3. La velocidad no basta: también debe medirse si el destino seleccionado es correcto.
4. La reutilización importa más que el número bruto de QR almacenados.
5. La comparación debe hacerse contra el método que cada usuario utiliza actualmente.
6. Los usuarios con pocos QR pueden obtener poco valor.
7. No existe un umbral universal demostrado de cantidad de QR.
8. Los QR similares requieren suficiente contexto para reducir errores.
9. Las reglas UX exactas para distinguir QR similares deben validarse.

## No demostrado

Las simulaciones no demuestran:

- demanda real de mercado;
- tamaño de segmento;
- disposición a pagar;
- retención real;
- ventaja cuantificada definitiva frente a alternativas;
- umbral universal de número de QR.
