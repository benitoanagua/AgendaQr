# Validación — Simulaciones

## Naturaleza

Se realizaron simulaciones sintéticas de perfiles y situaciones de uso para explorar comportamiento y puntos de fricción.

Son **evidencia sintética**, no evidencia de mercado.

## Resultados observados

Las simulaciones respaldan como hipótesis de validación:

- el valor aumenta cuando existen múltiples destinos reutilizables;
- la frecuencia de reutilización es más relevante que el número bruto de QR;
- recuperar QR desde mensajería es un caso de uso importante;
- distinguir destinos similares es un punto de riesgo;
- el método actual del usuario es el baseline apropiado.

## Regla

Las simulaciones no fijan por sí mismas requisitos de producto ni umbrales universales.
