# Validación — Resultados consolidados V1

Las simulaciones sintéticas y revisiones de dominio llevaron a los siguientes resultados aprobados:

1. La operación mínima debe ser `id + type + occurredAt`.
2. El comprobante debe poder guardarse sin operación.
3. La asociación comprobante ↔ operación debe poder corregirse.
4. Una operación puede tener múltiples comprobantes.
5. El duplicado debe advertirse sin bloquear.
6. Los cambios sensibles de una operación con comprobantes necesitan una única confirmación.
7. El archivo de evidencia no debe modificarse al editar la operación.
8. La eliminación debe liberar el archivo asociado y conservar solo una huella mínima.
9. La búsqueda funcional debe priorizar fecha, tipo, importe y persona/entidad.
10. La recepción de un comprobante no debe interpretarse como verificación financiera.

Estos resultados no son estadísticas de mercado.
