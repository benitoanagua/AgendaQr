# Agenda QR — Especificaciones y requisitos

Documentación estructurada a partir del material proporcionado.

## Criterio

Se conserva únicamente información que el material identifica como aprobada, confirmada, probada o como resultado de simulación.

No se convierten hipótesis en requisitos.

## Estructura

- `01-PRODUCTO`: definición, problema, alcance y límites.
- `02-REQUISITOS`: capacidades funcionales y requisitos confirmados.
- `03-MODELO`: modelo de dominio y relaciones.
- `04-UX`: flujos y capacidades de experiencia.
- `05-VALIDACION`: pruebas, simulaciones y resultados.
- `06-DECISIONES`: decisiones aprobadas.
- `07-FUERA-DE-ALCANCE`: elementos que no pertenecen al núcleo actual.
