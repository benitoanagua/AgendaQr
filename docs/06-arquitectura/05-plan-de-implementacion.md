# Plan de implementación

## Fase 1 — Base

- estructura KMP;
- `androidApp` e `iosApp`;
- módulos domain/data/presentation;
- convention plugins;
- version catalog;
- gates.

## Fase 2 — Núcleo funcional

- Destination;
- persistencia local;
- búsqueda;
- categorías;
- favoritos;
- recientes;
- crear/editar/eliminar/reemplazar.

## Fase 3 — QR

- cámara Android;
- galería Android;
- múltiples imágenes;
- decodificación QR;
- revisión antes de guardar;
- QR fullscreen;
- share inbound/outbound.

## Fase 4 — Xauxa

- tokens;
- componentes;
- estados;
- patterns;
- accesibilidad;
- motion;
- verificación visual.

## Fase 5 — Validación Android

- build;
- emulador/dispositivo;
- cámara;
- picker;
- share;
- persistencia;
- offline.

## Fase 6 — iOS

- integración del framework KMP;
- boundaries nativos;
- cámara/Photos/share/protección;
- validación mediante Xcode.

## Regla

No se adelanta una capacidad únicamente para cerrar una lista. Cada fase debe respetar la precedencia de fuentes y el alcance confirmado.
