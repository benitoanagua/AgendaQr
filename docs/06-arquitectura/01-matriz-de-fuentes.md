2. UI/UX: Xauxa Design System gana sobre implementaciones históricas.
3. Arquitectura técnica: se reutiliza de WaraWerse solamente cuando no contradice las dos reglas anteriores.
4. No se copian dominios de WaraWerse a Agenda QR.
